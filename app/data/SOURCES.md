# Data Sources

The sample word and grammar prompts in this project are derived from public
references and common introductory German grammar knowledge. The following
open resources were consulted when assembling the dataset:

- Wiktionary (CC BY-SA 4.0) for noun genders and sample glosses.
- Wikipedia German grammar overviews for general rule descriptions.

The dataset is intentionally small and meant as a starter set that can be
extended with additional open-source or public-domain content.
